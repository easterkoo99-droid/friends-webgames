# 친구들과 웹게임 (스파이폴 · 미니게임지옥)

Node.js + Express + Socket.IO로 만든 실시간 멀티플레이 웹게임 모음입니다.
방 상태는 서버 메모리에만 저장되므로 DB 없이 바로 배포할 수 있어요.

```
friends-webgames/
├─ server.js              서버 진입점 (정적 파일 + Socket.IO)
├─ games/
│  ├─ spyfall.js          스파이폴 서버 로직
│  ├─ quizparty.js        미니게임지옥 서버 로직
│  ├─ quizdata.js         미니게임지옥 문제 은행 (여기서 문제 추가)
│  └─ util.js             공용 유틸
├─ public/
│  ├─ index.html          게임 선택 화면
│  ├─ spyfall.html        스파이폴 화면
│  └─ quizparty.html      미니게임지옥 화면
├─ package.json
├─ render.yaml            Render 블루프린트 (선택)
└─ .gitignore
```

## 1. 내 컴퓨터에서 실행

```bash
npm install
npm start
# http://localhost:3000
```

같은 와이파이의 다른 기기에서는 `http://내컴퓨터IP:3000` 으로 접속하면 돼요.

## 2. GitHub에 올리기

1. GitHub에서 **New repository** 로 빈 저장소를 만듭니다. (예: `friends-webgames`)
2. 이 폴더의 파일 전체를 올립니다. (`node_modules`는 제외)
   - 터미널: `git init && git add . && git commit -m "first commit" && git branch -M main && git remote add origin <저장소 주소> && git push -u origin main`
   - 터미널이 어렵다면 저장소 페이지의 **Add file → Upload files** 에 폴더 안 파일들을 드래그해도 돼요.
   - `package.json`, `server.js`가 저장소 **맨 위 경로**에 있어야 해요.

## 3. Render에 배포하기

1. [render.com](https://render.com) 에서 GitHub 계정으로 로그인합니다.
2. **New → Web Service** → 방금 만든 저장소를 연결합니다.
3. 설정값
   - Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: `Free`
4. **Create Web Service** 를 누르면 몇 분 뒤 `https://이름.onrender.com` 주소가 생겨요.
   (`render.yaml`을 같이 올렸다면 **New → Blueprint** 로 위 설정을 자동 적용할 수도 있어요.)
5. 이후에는 GitHub에 `git push` 할 때마다 자동으로 다시 배포됩니다.

## 스파이폴 진행 방식

- 입장한 사람은 **게임 준비**를 눌러야 참가자가 돼요. 준비한 사람이 3명 이상이면 **준비한 누구든** 시작할 수 있어요. (한 판 최대 8명, 방 정원 10명)
- 시민은 **장소만** 받아요. (역할/직업은 없어요) 스파이는 장소를 몰라요.
- 판이 진행 중일 때 들어오면 **관전자**예요. 준비를 눌러 두면 다음 판부터 참가해요.
- 질문은 A→B→C→D 순으로 이어져요. 질문을 받은 사람은 **대답을 적고**, 다음 질문 상대를 지목해 질문해요.
- **스파이 지목 투표**는 화면을 가리지 않고 상단에 표시돼요. 지목된 사람을 뺀 참가자 **전원이 찬성**해야 확정되고, 한 명이라도 반대하면 바로 부결돼요. 누가 어떻게 투표했는지 모두에게 공개돼요. (투표 시간 90초, `VOTE_SEC`)
- **승점제**: 방이 유지되는 동안 판마다 점수가 누적돼요. 1등(점수 1점 이상)에게는 이름표에 👑이 계속 붙어요.

  | 결과 | 스파이 | 시민 |
  |---|---|---|
  | 시민 승리 (스파이 지목 가결) | 0 | 전원 +1, 지목을 연 사람 +1 추가 |
  | 시민 승리 (스파이가 장소를 틀림) | 0 | 전원 +1 |
  | 스파이 승리 (제한 시간 종료) | +2 | 0 |
  | 스파이 승리 (장소를 맞힘 / 시민 오지목 가결) | +3 | 0 |
  | 중단 (스파이 이탈, 인원 부족) | 점수 없음 | 점수 없음 |

  점수표는 `games/spyfall.js`의 `CFG.SCORE`에서 바꿀 수 있어요. 서버에 저장하지 않아서 방이 사라지거나 재배포하면 초기화돼요.
- **전체 채팅**은 참가자·관전자 모두 쓸 수 있고, 닉네임마다 이모지와 색상이 달라요. PC에서는 오른쪽에, 모바일에서는 `💬 채팅` 탭에서 볼 수 있어요.

## 미니게임지옥

미니게임 **12종 중 10종**이 **매 판 랜덤으로 뽑혀 랜덤한 순서**로 한 번씩 나오는 10라운드 점수제 대결이에요. 전 라운드 점수를 합산해 순위를 정해요. (탈락 없음) 방/준비/관전/채팅/👑은 스파이폴과 같아요. 다음 라운드가 무엇인지는 그 라운드가 시작될 때 공개돼요.

| 미니게임 | 문제 수 | 규칙 / 점수 |
|---|---|---|
| 꽁꽁 (주관식 골든벨) | 4 | 20초 안에 답을 **한 번만** 제출, 시간이 끝나면 정답과 모두의 답이 한꺼번에 공개 · 정답 +10점, 빨리 낼수록 최대 +5점 |
| 연상퀴즈 | 3 | 힌트 5개가 6초 간격으로 공개 · 10·8·6·4·2점 · 첫 정답자 +3 |
| OX 퀴즈 | 5 | 정답 +8점, 빨리 고를수록 최대 +4점 |
| 초성 퀴즈 | 4 | 먼저 맞힌 순서대로 10·7·5점, 그 뒤는 3점 · 12초 뒤 첫 글자 힌트 |
| 인물 맞추기 | 3 | 힌트 4개가 7초 간격으로 공개 · 10·7·5·3점 · 첫 정답자 +3 |
| 업다운 | 3 | 비밀 숫자(1~50 → 1~100 → 1~200)를 맞히기. 내 추측마다 UP/DOWN 힌트 · 먼저 맞힌 순서대로 10·7·5·3점 |
| 다른 그림 찾기 | 4 | 비슷한 그림 30개 중 다른 하나 찾기. 틀리면 1.5초 잠김 · 먼저 찾은 순서대로 10·7·5·3점 |
| 암산 대결 | 4 | 덧셈 → 뺄셈 → 곱셈 → 혼합 계산 · 먼저 맞힌 순서대로 10·7·5·3점 |
| 기억력 | 3 | 그림 4·5·6개를 잠깐 보여주고 같은 순서로 누르기 · 제자리에 맞힌 그림마다 +2점, 전부 맞히면 +4점 |
| 반응속도 | 4 | 초록색이 되는 순간 누르기. 일찍 누르면 0점 · 빠른 순서대로 10·8·6·4점 |
| 10초 맞추기 | 3 | 스톱워치가 올라가고, 정확히 10초에 STOP! 숫자는 5초 → 3초 → 처음부터 안 보임 · 오차 ±0.1초 15점 · ±0.25초 12점 · ±0.5초 9점 · ±1초 6점 · ±2초 3점 · ±3초 1점 |
| 끝말잇기 | 1 | 차례대로 단어를 이어요(10초, 점점 짧아져요). 시간 초과면 탈락 · **탈락 순서대로 순위 점수** 15·10·7·5점, 그 뒤 3점 · 두음법칙(리→이, 라→나 등) 인정 · 최대 2분 |

- **끝말잇기 이의 제기**: 사전이 없어서 단어가 실제로 있는지는 서버가 알 수 없어요. 대신 단어를 낸 뒤 3.5초 동안 다른 참가자가 `이의 제기`를 누를 수 있고(1인 2회), 작성자를 뺀 생존자의 과반이 이의 제기하면 그 단어는 무효가 돼요. 무효가 되면 탈락은 아니고 같은 사람이 6초 안에 다시 내야 해요. 무효가 된 단어는 다시 쓸 수 없어요.
- **문제 추가**: 꽁꽁/연상/OX/초성/인물 문제는 `games/quizdata.js`에 같은 형식으로 추가하면 돼요. (파일 위쪽에 형식 설명이 있어요) 나머지 7종은 매번 새로 만들어져서 문제를 따로 넣을 필요가 없어요.
- **라운드 구성/점수/시간**: `games/quizparty.js`의 `GAMES`(각 게임 설정)와 `CFG`에서 바꿀 수 있어요. `CFG.ROUNDS`를 12로 바꾸면 12종이 모두 나오고, `CFG.SHOW_UPCOMING = true`로 바꾸면 다음 라운드 이름을 미리 보여줘요.
- **새 미니게임 추가**: `GAMES`에 항목 하나를 더하고 `ORDER`에 이름을 넣으면 돼요.
- 한 판 2~12명, 방 정원 16명이에요.

## 알아두기

- **무료 플랜은 15분 동안 접속이 없으면 서버가 잠들어요.** 다시 열면 첫 접속에 30~60초가 걸립니다. 약속 시간 전에 한 번 열어 두세요.
- 서버가 재시작/재배포되면 진행 중이던 방은 모두 사라져요. (메모리 저장)
- 새로고침이나 일시적인 끊김은 `localStorage`의 토큰(`spy_token`/`spy_room`)으로 같은 자리로 복귀합니다.
- 초대 링크: `/spyfall.html?spy_room=코드`

## 설정 조정

`games/spyfall.js`의 `CFG`(인원·시간)와 `LOCATION_NAMES`(장소 50곳)에서 바꿀 수 있어요.
