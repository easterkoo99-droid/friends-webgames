# 게임방

친구들과 링크 하나로 바로 한 판. 방을 만들고, 대기실에서 게임을 고르고, 끝나면 다른 게임으로 바로 바꿀 수 있어요.
(Node.js + Express + Socket.IO, 방 상태는 서버 메모리에 저장돼요)

## 지금 있는 게임
- 📍 **우리가 있는 곳은?** (3~8명): 한 명만 장소를 몰라요. 질문과 대답으로 스파이를 찾아내는 게임이에요. (코드 이름: `spyfall`)
- 🩸 **오늘도 이 마을엔 피가 흐른다** (5~15명): 숨은 직업으로 악마를 찾는 마을 추리극이에요. (코드 이름: `village`)

### 오늘도 이 마을엔 피가 흐른다 규칙
원작(숨은 정체 추리 보드게임)의 규칙을 그대로 따르고, **직업 이름과 설명은 이 게임에서 새로 만든 것**이에요. 사람 이야기꾼이 하던 일은 서버가 자동으로 해요.
- 5~15명. 모두 비밀 직업을 받아요. **마을 편**(마을 사람·외부인)은 악마를 처형하면 이기고, **악**(악마 1명 + 하수인)은 살아남은 사람이 2명이 되면 이겨요.
- **밤**: 능력이 있는 사람만 선택해요. 악마는 둘째 밤부터 한 명을 습격하고, 결과는 아침에 ‘내 정보 기록’에 쌓여요. 첫 밤에 악마와 하수인은 서로를 알고, 악마는 마을에 없는 직업 3개(허세용)를 받아요.
- **낮**: 토론과 귓속말 → 지목(한 사람당 한 번) → 찬반 투표. 살아 있는 사람 절반 이상이 찬성한 가장 높은 득표자가 처형돼요. 동점이면 아무도 처형되지 않아요. 죽은 사람은 투표에 한 번(찬성할 때) 참여할 수 있어요(유령표).
- **귓속말**: 낮에 누구와도 비공개로 이야기할 수 있어요. 누가 누구와 이야기하는지는 일지에 보이지만 내용은 당사자만 볼 수 있어요.
- **독과 취함**: 독약상의 독이나 술꾼 때문에 정보 직업이 **거짓 정보**를 받을 수 있어요. 은둔자와 첩자는 다른 사람의 능력에 다른 직업·편으로 **보일 수** 있어요.
- **직업 22종** (원작 입문 시나리오와 같은 구성):
  - 마을 사람 13: 방물장수, 서당 훈장, 포졸, 주모, 이웃집 할머니, 점쟁이(오해 유발자 있음), 장의사, 약초꾼, 까마귀지기, 성녀, 사냥꾼, 병사, 이장
  - 외부인 4: 하인, 술꾼, 은둔자, 성자
  - 하수인 4: 독약상, 첩자, 붉은 여인, 음모가
  - 악마 1: 피의 군주 (자신을 습격해 하수인에게 자리를 넘길 수 있어요)
  - 직업 설명은 게임 안의 ‘📖 직업 도감’에서 볼 수 있어요.
- 인원별 구성(마을 사람/외부인/하수인): 5명 3/0/1, 6명 3/1/1, 7명 5/0/1, 8명 5/1/1, 9명 5/2/1, 10명 7/0/2, 11명 7/1/2, 12명 7/2/2, 13명 9/0/3, 14명 9/1/3, 15명 9/2/3. (음모가가 있으면 외부인 +2, 마을 사람 -2)
- **원작과 다른 점**: 이야기꾼이 자동이라 거짓 정보와 ‘다르게 보임’, 이장의 대리 사망이 무작위(50%)로 정해지고, 판정에 사람의 재량이 없어요. 낮은 토론 → 지목 단계로 나뉘고 시간 제한이 있어요. 여행자, 미리 정한 시나리오 선택, 오프라인 진행은 없어요.
- 직업 이름과 설명은 `games/village.js` 위쪽 `ROLES`에서 고치면 화면의 도감도 같이 바뀌어요. 시간(밤/토론/지목/투표)과 승점은 같은 파일의 `CFG`에서 고쳐요.

## 쓰는 방법
1. 주소를 열면 닉네임이 자동으로 채워져 있어요. `방 만들기`를 누르면 4자리 방 코드가 생겨요.
2. 위쪽 `초대 링크 복사`로 친구들에게 보내면, 링크를 여는 순간 방 코드가 채워져 있어요. `입장`만 누르면 돼요.
3. 대기실에서 게임 카드를 골라요. (누구든 바꿀 수 있어요) 인원 조건을 채우도록 `준비`를 누르고, 준비한 누구든 `게임 시작`을 눌러요.
4. 게임 중에도 `게임 바꾸기`로 대기실에 돌아와서 다른 게임을 고를 수 있어요. 점수와 👑는 방에 계속 남아요.
5. 게임 중에 들어온 사람은 관전자예요. `다음 판 준비`를 눌러 두면 다음 판부터 참가해요.

휴대폰에서는 아래 탭(🎮 게임 / 💬 채팅)으로, PC에서는 채팅이 오른쪽에 같이 보여요.

## 폴더 구성
```
server.js            서버 시작 (Express + Socket.IO)
hub.js               방 코드, 입장, 닉네임, 채팅, 준비, 관전, 점수판, 게임 선택/전환
games/
  index.js           게임 목록 (새 게임은 여기에 한 줄 추가)
  spyfall.js         ‘우리가 있는 곳은?’ 규칙 (서버)
  village.js         ‘오늘도 이 마을엔 피가 흐른다’ 규칙 (서버)
  util.js            공용 도구
public/
  index.html         화면 전체 (입장, 방, 대기실, 채팅) — 패치노트도 여기 PATCHNOTES 에서 고쳐요
  games/spyfall.js   ‘우리가 있는 곳은?’ 화면
  games/village.js   ‘오늘도 이 마을엔 피가 흐른다’ 화면
```

## 게임 추가하기
게임 하나는 **서버 파일 1개 + 화면 파일 1개**예요. 추가하면 대기실에 카드가 자동으로 생겨요.

1. `games/내게임.js` — spyfall.js 를 참고해서 아래 모양으로 만들어요.
   ```js
   module.exports = {
     id: 'mygame', name: '내 게임', emoji: '🎯', desc: '한 줄 소개', rules: ['규칙1', '규칙2'],
     min: 2, max: 6,                       // 한 판 인원
     create(api) {                         // api: broadcast(room), chatSys(room, 글), addScore(room, 플레이어, 점수)
       return {
         start(room, gamers) { room.g = { ... }; },       // 게임 상태는 room.g 에 저장
         view(room, pid) { return { ... }; },             // 이 사람에게 보여줄 상태 (비밀 정보는 빼기!)
         action(room, player, msg) { return { ok: true }; },  // 화면에서 보낸 동작 처리
         isFinished: (room) => room.g && room.g.phase === 'ended',
         dispose(room) { room.g = null; },                // 타이머 정리
         // onLeave(room, player), onDrop(room, player) 는 필요할 때만
       };
     },
   };
   ```
2. `games/index.js` 에 `require('./내게임'),` 한 줄 추가.
3. `public/games/내게임.js` — public/games/spyfall.js 를 참고해서 `GAME_UI.mygame = { mount(ctx), update(S, G), unmount() }` 를 등록해요.
4. `public/index.html` 의 `<script src="/games/spyfall.js">` 아래에 `<script src="/games/내게임.js"></script>` 한 줄 추가.

## 설정
- `hub.js` 위쪽 `CFG`: 방 정원, 연결 끊김 유지 시간, `HOST_ONLY_SWITCH`(true 로 바꾸면 방장만 게임을 바꿀 수 있어요).
- `games/spyfall.js` 위쪽 `CFG`: 제한 시간, 투표 시간, 점수표.

## 배포 (Render)
- Root Directory: 이 폴더 (`package.json`이 있는 폴더), Build: `npm install`, Start: `node server.js`
- 상태 확인: `/healthz`
- 무료 플랜은 15분 동안 접속이 없으면 잠들어요. 다시 열면 30~60초 걸려요. 새로 배포하면 진행 중인 방은 사라져요.
